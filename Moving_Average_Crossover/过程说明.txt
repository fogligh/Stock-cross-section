# 多因子量化策略开发与验证流程

## 一、策略概述

本策略基于技术面因子（移动平均线）构建日线交易逻辑，通过严格的参数优化和回测验证，最终结合机器学习模型进行信号增强，形成完整的量化投资策略体系。

---

## 二、数据准备

### 2.1 数据源
- **主数据文件**：`final_200stocks_with_benchmark_2020_2025.csv`
- **基准股票**：`000002.SZ`（万科A）
- **数据频率**：日线数据

### 2.2 核心因子列
| 因子名称 | 说明 |
|---------|------|
| `ma_5` | 5日均线 |
| `ma_10` | 10日均线 |
| `open` | 开盘价 |
| `high` | 最高价 |
| `low` | 最低价 |
| `close` | 收盘价 |

---

## 三、交易逻辑设计

### 3.1 开仓条件（全部满足）

| 序号 | 条件 | 详细说明 |
|------|------|----------|
| 1 | **均线金叉** | MA5上穿MA10（即：`ma_5 > ma_10` 且 前一日 `ma_5 <= ma_10`） |
| 2 | **均线斜率** | 当前MA5斜率大于0（`ma_5 > REF(ma_5, 1)`） |
| 3 | **K线形态** | 阳线上影不超过实体的75%；阴线下影不超过实体的90% |
| 4 | **非涨停** | 当日收盘价 < 涨停价（根据板块涨跌停限制判断） |
| 5 | **价格约束** | `(MA5 - REF(MA5, 1)) <= 0.05 × 当日收盘价` |
| 6 | **KDJ约束** | KDJ(9,3,3)>60  and KDJ(72,24,24)<85,KDJ(72,24,24)斜率>-0.5 |

### 3.2 平仓条件（满足任一）

| 序号 | 条件 | 详细说明 |
|------|------|----------|
| 1 | **固定止损** | 持仓亏损达到5%（相对开仓价） |
| 2 | **均线死叉或斜率异常** | `(MA5 - MA10) < REF(MA5 - MA10, 1)` 或 `当前MA5斜率 > 开仓时MA5斜率的1.88倍` |

## 四、参数设计

### 4.1 时间窗口参数

| 参数 | 数值 | 说明 |
|------|------|------|
| 训练窗口 | 252天 | 1年交易日 |
| 测试窗口 | 63天 | 1个季度交易日 |
| 滚动步长 | 21天 | 每月滚动一次 |

### 4.2 策略验证周期
- **样本外验证**：选取1年数据进行策略稳健性验证
- **验证方法**：滚动窗口测试 + 回撤归因分析

---

## 五、策略稳健性验证

### 5.1 滚动窗口测试指标

| 指标 | 理想标准 | 计算方法 |
|------|----------|----------|
| 夏普比率衰减 | `< 0.3` | 各窗口夏普比率的波动范围 |
| 胜率波动 | `< 10%` | 各窗口胜率的标准差 |

### 5.2 滚动IC/IR序列

| 指标 | 定义 | 意义 |
|------|------|------|
| **IC** | 因子值与未来收益的秩相关系数 | 衡量因子预测能力 |
| **IR** | IC均值 / IC标准差 | 衡量因子预测稳定性 |

### 5.3 最大回撤归因分析

#### 目的
拆分回撤来源，区分市场因素（β）和策略因素（α）

#### 方法
```
策略收益 = 市场收益（β）+ 超额收益（α）
```

#### 归因模型：Fama-French 三因子模型

| 因子 | 说明 |
|------|------|
| **市场因子（MKT）** | 市场超额收益 |
| **规模因子（SMB）** | 小市值 - 大市值 |
| **价值因子（HML）** | 高账面市值比 - 低账面市值比 |

#### 分析目标
- 计算策略在各因子上的暴露度
- 识别回撤期间的因子暴露变化
- 判断回撤是源于市场系统性风险还是策略本身问题

## 六、机器学习建模流程

### 6.1 股票池筛选
- **筛选标准**：收益排名前60%的股票
- **筛选周期**：每个训练窗口重新计算

### 6.2 预测目标
- **信号预测**：预测未来N日收益率方向（分类）
- **收益预测**：预测未来N日收益率数值（回归）

### 6.3 模型选择与对比

| 模型 | 用途 | 特点 |
|------|------|------|
| **LightGBM** | 多因子选股、信号预测 | 高效、支持大规模数据、可处理缺失值 |
| **XGBoost** | 多因子选股、分类预测 | 正则化强、防止过拟合、解释性好 |
| **Random Forest** | 特征探索、基准模型 | 可解释性强、特征重要性评估 |

### 6.4 模型训练流程

```
┌─────────────────────────────────────────────────────────┐
│                   训练流程                               │
├─────────────────────────────────────────────────────────┤
│  1. 滚动窗口训练（252天训练，63天测试，步长21天）        │
│  2. 特征工程：技术因子 + 价量因子 + 基本面因子           │
│  3. 标签构建：未来N日收益率（N=1,5,10,20）              │
│  4. 模型训练与超参数调优                                 │
│  5. 模型集成与信号合成                                   │
│  6. 预测结果验证（IC/IR分析）                           │
└─────────────────────────────────────────────────────────┘
```

## 七、回测执行与评估

### 7.1 回测配置

| 参数 | 设定值 |
|------|--------|
| 基准 | `000002.SZ` |
| 初始资金 | 1亿 |
| 持仓数量 | 动态（根据信号） |
| 交易费率 | 双边14bp |
| 换手限制 | ≤30%/日 |

### 7.2 回测输出指标

| 指标类别 | 具体指标 |
|----------|----------|
| **收益指标** | 总收益率、年化收益率 |
| **风险指标** | 年化波动率、最大回撤 |
| **风险调整指标** | 夏普比率、卡玛比率 |
| **交易指标** | 胜率、盈亏比、换手率 |
| **对比指标** | 超额收益、信息比率 |

### 7.3 对比分析
- **对比对象**：
  1. 原始策略（无ML增强）
  2. LightGBM模型策略
  3. XGBoost模型策略
  4. Random Forest模型策略

- **对比维度**：
  - 净值曲线
  - 各绩效指标对比表
  - 回撤对比分析
  - 月度收益热力图
